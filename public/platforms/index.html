This page is internal tooling for tuning how platform icons render in the Vertex Order listings — not something you need to visit as a reader. The Zoomed grid is roughly twice page size for easier visual tweaking; the Page size grid renders each icon through PlatformIcon.dc.html at the size used in listing rows — the same data, at 1x. Icons are credited in full in NOTICE. See Help Wanted below, or use the discussion page to propose new platforms or changes.
